# Вариант 9 — Система управления складом с использованием TDD

## Возможности
- Добавление новых товаров
- Изменение количества товара
- Поступление товара
- Отгрузка товара
- Проверка доступного остатка (нельзя отгрузить больше, чем есть)
- История складских операций
- Хранение данных в SQLite
- Автоматические тесты на unittest

## Файлы
- `warehouse.py` — бизнес-логика и база данных
- `app.py` — графический интерфейс на Tkinter (весь интерфейс на русском)
- `test_warehouse.py` — автоматические тесты

## Требования
Python 3.10+ (Tkinter обычно входит в установку Python для Windows).

## Запуск приложения
Откройте терминал в папке проекта и выполните:

```bash
python app.py
```

При первом запуске автоматически создается база `warehouse.db`.

## Запуск тестов
```bash
python -m unittest -v
```

## Методология TDD
1. RED — сначала написать тест и убедиться, что он падает.
2. GREEN — реализовать минимальный код, чтобы тест прошел.
3. REFACTOR — улучшить код, сохранив успешные тесты.

В проекте тесты используют временную базу данных, поэтому тестовые данные не попадут в рабочую `warehouse.db`.
